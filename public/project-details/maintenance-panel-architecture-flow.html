    Backend Architecture Overview

    Click a different node, or the same node again, to change selection.

    This diagram traces one request and one scheduling action through the maintenance panel — built on a single Cloudflare Worker, a D1 database, the Cloudflare Rulesets API, and a Cron Trigger.

    💡 Interactive diagram: click any component on the left to learn its role.

    Key components
    • React UI: Command Center, Fleet, and Calendar views, served as static assets
    • Cloudflare Worker: serves the UI, the REST API, and the Cron handler — one deploy
    • D1 Database: durable state — active windows and the append-only audit log
    • Rulesets API: the per-domain Snippet Rule that intercepts traffic at the edge
    • Cron Trigger: sweeps every minute to activate and retract windows automatically
    Data flow

    Visitors are matched against the Snippet Rule at the edge — if a window is active, they get an instant 503, before ever reaching origin. Meanwhile the Browser talks to the Worker over a REST API to schedule windows, which the Worker persists in D1 and mirrors to the Rulesets API. Every minute, the Cron Trigger sweeps D1 and flips rules on or off automatically.

    Architecture focus

    Fully edge-native maintenance orchestration — zero origin servers, self-scheduling, self-expiring, fully audited.
